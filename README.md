# Hostify Tests Store

Plataforma de venta y acceso a tests de liderazgo y hospitalidad.

## Tests

- ✅ Checkbox 5 Niveles
- ✅ DISC
- ✅ 5 Niveles de Liderazgo
- ✅ HII (Hospitality Intelligence Index)
- ✅ 5 Casas

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Supabase (Auth + DB)
- Stripe (Pagos)

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Abre http://localhost:3000
